**Subject:** TCST target-clarity decay-rate sweep

Hello,

I ran a set of simulations where I adjusted the decay rate used in the target
clarity map generation. As a reminder, we define the target clarity map as

\[
\delta(p,t)=-\lambda_{cd}\left(\mu(p,t)-w_{\mathrm{rated}}\right)^2,
\qquad
\overline q(p,t)=q_{\mathrm{rated}}e^{\delta(p,t)}.
\]

Thus, as \(\lambda_{cd}\to0\), the target clarity becomes spatially constant,
and we expect the adaptive ergodic strategy to match the nonadaptive ergodic
strategy. I swept
\(\lambda_{cd}\in\{0,0.025,0.05,0.1,0.25,0.5,0.75,1.0\}\) in both the
half-domain and moving-pockets simulation studies. For each value, I reran all
eight half-domain strategies and all seven moving-pockets strategies with the
same initial condition, mission duration, environment, and measurement-noise
seed.

The main conclusions are as follows.

The \(\lambda_{cd}=0\) sanity check passes exactly for the ergodic
strategies. In both environments, the adaptive and nonadaptive ergodic runs
have identical trajectories and identical values of wind RMSE, clarity deficit,
and in-target measurement percentage. This confirms that the nonadaptive
ergodic strategy is recovered as the zero-decay special case.

For the adaptive ergodic strategy in the half-domain environment, the results
are:

| \(\lambda_{cd}\) | Wind RMSE | Own-target deficit | Fixed-target deficit | In-target measurements |
|---:|---:|---:|---:|---:|
| 0 | 1.671 | 0.16525 | 0.08619 | 46.66% |
| 0.025 | 2.101 | 0.08669 | 0.08669 | 91.96% |
| 0.05 | 2.535 | 0.09317 | 0.09317 | 92.84% |
| 0.1 | 2.686 | 0.09590 | 0.09590 | 95.21% |
| 0.25 | 2.839 | 0.09425 | 0.09425 | 95.57% |

A small positive decay rate substantially changes the behavior. Moving from
zero to 0.025 increases targeted sampling by 45.30 percentage points while
increasing global RMSE by 25.7%. Increasing the rate from 0.025 to 0.25 gains
only another 3.61 percentage points of targeted sampling, while global RMSE
increases by an additional 35.2% relative to the 0.025 run. The fixed-target
deficit also becomes worse. Thus, increasing target selectivity beyond a small
positive value provides little additional benefit in the static environment.

The moving-pockets response is more strongly non-monotonic. Adaptive ergodic
control reaches its highest in-target percentage at \(\lambda_{cd}=0.1\):
79.53%, compared with 10.97% at zero. However, the fraction falls to 32.36% at
0.25. My interpretation is that a sharper target map is more sensitive to
estimation error. When the estimated pocket is displaced from the true pocket,
the controller can strongly exploit the wrong location.

The plots report two definitions of clarity deficit. The **own-target deficit**
evaluates each run against the target generated by its own \(\lambda_{cd}\), so
it answers whether the controller met the requirement it was given. The
**fixed-target deficit** evaluates every trajectory against the same
ground-truth target generated with \(\lambda_{cd}=0.25\), which permits a direct
comparison across the sweep. This distinction is important because increasing
\(\lambda_{cd}\) lowers requested clarity over most of the domain. The
own-target deficit can therefore decrease because the target became narrower,
even if the trajectory did not improve. This is visible in the nonadaptive and
transect controls: their paths, RMSE, and collected measurements do not change
with \(\lambda_{cd}\), but their own-target deficits change while their
fixed-target deficits remain constant.

Overall, these results suggest that \(\lambda_{cd}\) controls an explicit
exploration--exploitation tradeoff:

- \(\lambda_{cd}=0\) produces broad, nonadaptive ergodic coverage;
- a small positive value efficiently biases sampling toward interesting
  regions;
- a larger value can over-concentrate the trajectory and leave portions of the
  desired region uncovered; and
- in a dynamic environment, excessive selectivity can amplify target-estimation
  error.

For these runs, 0.025 appears to be the clearest balanced value across both
environments, while 0.1 is preferable if moving-target acquisition is the
primary objective. I do not think the current evidence supports treating 0.25
as universally optimal.

One implementation detail remains before applying the same zero-decay argument
to BB-IPP: the adaptive and nonadaptive BB-IPP controllers currently optimize
different reward maps (target clarity versus clarity deficit). Their
\(\lambda_{cd}=0\) runs are consequently not identical. The ergodic comparison
does not have this issue and passes the zero-decay check exactly.

I have attached the consolidated sweep plots, measurement histograms, and the
most informative adaptive and nonadaptive ergodic path animations at
\(\lambda_{cd}=0,0.025,0.1,\) and 0.25. These are currently matched single-seed
sensitivity runs, so I would treat the apparent optima as mechanistic evidence
